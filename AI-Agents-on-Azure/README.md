# Azure AI Agents Exercise Workspace

This repository contains hands-on exercises for building, customizing, and orchestrating AI agents using Azure AI services and the Semantic Kernel. Each folder demonstrates a different scenario or tool integration.

## Structure

- **01-build-ai-agents/**  
  Build a basic AI agent that analyzes data from a file using Azure AI Agents SDK.

- **02-custom-tool/**  
  Extend an agent with custom Python functions for support ticketing and email escalation.

- **03-multiagent/**  
  Demonstrates multi-agent orchestration for ticket triage using specialized agents.

- **04-mcp-tool/**  
  Integrates the Microsoft Content Platform (MCP) tool for documentation search via an agent.

- **05-semantic-kernel/**  
  Uses Semantic Kernel to process expense data and simulate sending an email.

- **06-multiagent-semantic-kernel/**  
  Multi-agent orchestration with Semantic Kernel for incident management and DevOps automation.
